Este pacote não precisa de Node.js, npm ou banco de dados.

## Abrir

1. No VS Code, clique em **Arquivo > Abrir Pasta**.
2. Escolha a pasta `EntregaPlus-VSCode`.
3. Abra `index.html`.
4. Clique com o botão direito e escolha **Open with Live Server**.

Se não tiver o Live Server, instale a extensão **Live Server**, de Ritwick Dey. Também é possível dar dois cliques em `index.html` e abrir diretamente no navegador.

## Arquivos

- `index.html`: estrutura das duas telas.
- `styles.css`: design e responsividade.
- `script.js`: botões e interações.

## Demonstração

- Alterne entre Experiência do cliente e Central logística.
- Clique em Simular avanço.
- Escolha e confirme uma janela.
- Otimize rotas e aplique a recomendação.

Os dados são simulados para fins acadêmicos.
